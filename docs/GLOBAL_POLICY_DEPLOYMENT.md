# 操作前确认

`GLOBAL_POLICY.md` 是个人全局 Spec Kit 规则的仓库内来源。全局规则块使用固定开始和结束标记，不维护政策版本号。本页只说明人工更新，不会自动部署，也不修改用户目录中的全局 `AGENTS.md`。

全局规则只负责判断是否询问用户为新项目启用 Spec Kit，并在用户同意后通过固定本机路径读取 Reference。项目内流程由初始化时写入目标项目 `AGENTS.md` 的规则块负责；已 Spec 项目的会话不依赖个人全局文件或 Reference。

# 人工更新步骤

1. 确认 Agent 实际加载的个人全局规则文件。
2. 查看本地 `GLOBAL_POLICY.md` 的固定开始和结束标记及完整内容；标记只用于定位规则块。
3. 只将 `SPEC-KIT-GLOBAL-POLICY` 标记内的块更新到个人文件，原样保留文件其余内容。
4. 检查标记是否唯一、顺序正确，确认没有覆盖文件中的其他规则。不要添加或更新政策版本号。
5. 在新会话中确认 Agent 已加载更新后的个人规则。

如果个人规则文件中的标记缺失、重复或顺序异常，停止人工替换并先明确边界。本仓库不提供自动部署器、个人规则覆盖操作或备份副本。
